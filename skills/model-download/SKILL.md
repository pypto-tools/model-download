# Model Download

先读仓库 [README](../../README.md) 中的下载约束和用法。

1. 确认模型 ID、来源、目标目录、下载账号、授权范围、磁盘余量，以及目标服务器允许的时区和下载窗口。没有明确窗口时不启动下载。
2. 不用 AI 代理下载；优先从国内模型源直连。通用脚本固定使用 ModelScope 国内站，但不会限制时段，也会使目标目录对所有本机用户可读。仅在这些行为符合任务要求时使用。
3. 定时下载使用会在窗口结束停止下载进程的入口；仓库中的 DeepSeek 夜间脚本只适用于它写死的模型、路径和北京时间窗口。换模型或服务器时先检查并修改入口，不直接复用。
4. 下载后检查日志和完成标记，运行 `verify_model.sh` 做大小与哈希校验；完成后移除临时定时任务。不要随意删除 `.msc` 进度索引。

报告模型版本、来源、目标目录、下载窗口及校验结果；不输出凭据或带认证信息的 URL。
